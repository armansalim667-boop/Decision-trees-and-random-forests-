# Task 5: Decision Trees and Random Forests

## Objective
The objective of this task is to learn tree-based machine learning models for classification and understand ensemble learning using Random Forests.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## Dataset
Heart Disease Dataset

## Steps Performed

1. Loaded the Heart Disease dataset.
2. Performed basic data exploration and checked for missing values.
3. Split the dataset into training and testing sets.
4. Trained a Decision Tree Classifier.
5. Evaluated the model using accuracy score.
6. Visualized the Decision Tree.
7. Controlled overfitting by limiting tree depth.
8. Trained a Random Forest Classifier.
9. Compared the performance of Decision Tree and Random Forest models.
10. Analyzed feature importance.
11. Evaluated the model using 5-fold cross-validation.

## Results

- Decision Tree Classifier was successfully trained and evaluated.
- Random Forest achieved better generalization compared to a single Decision Tree.
- Feature importance helped identify the most influential attributes in predicting heart disease.
- Cross-validation provided a more reliable estimate of model performance.

## Key Concepts Learned

- Decision Trees
- Entropy and Information Gain
- Overfitting and Tree Pruning
- Random Forests
- Bagging
- Feature Importance
- Cross-Validation

## Conclusion

Decision Trees are simple and interpretable models, but they can overfit the training data. Random Forests improve performance by combining multiple Decision Trees, resulting in better accuracy and robustness.
